TERN — DEMO RECORDING CUE SHEET
Narration: walkthrough.m4a  (5 min 54 sec, male voice)

SETUP
  1. QuickTime Player -> File -> New Screen Recording
  2. Options -> Microphone: None      (you want the file's audio, not the room)
  3. Have http://localhost:8200/#/map open and already signed in (test1 / 12345678)
  4. Press Record, then immediately play walkthrough.m4a

Tip: one stop (Lisbon) is enough if you are short of time. The build takes
about a minute, which the narration covers.
